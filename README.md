# free-resources

免费云资源与保活脚本。

## 内容

- `keepalive-simular-box.py` — Simular box 保活脚本。box 连续睡 14 天会被删除，
  每周用 MCP 连接唤醒一次即可重置计时。用法见脚本开头的说明，
  需要先在 https://box.simular.ai/access 创建 personal key，
  设成环境变量 `SIMULAR_BOX_KEY` 再跑。key 不要写进仓库、不要发到聊天里。
